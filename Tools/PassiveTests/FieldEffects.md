# 스킬 필드효과

스킬 에디터의 ROE에서 타일을 선택하고 **필드 효과**를 지정합니다. **필드 세기**는 기본 1, **필드 지속 턴**은 기본 3입니다. 바람은 방향도 지정할 수 있습니다. 기존 스킬 에셋의 enum 번호와 필드명은 유지합니다.

| 효과 | 적 턴 시작 시 적용 |
| --- | --- |
| Fire / 화염 | 해당 칸의 적에게 세기만큼 피해 |
| Electric / 전기 | 해당 칸의 적에게 세기만큼 피해 |
| Ice / 얼음 | 해당 칸의 적이 이번 턴 결계에 피해를 주지 못함 |
| Wind / 바람 | 해당 칸의 적을 설정한 방향으로 세기만큼 밀침. 점유 칸과 맵 경계에서 멈춤 |
| Earth / 대지 | 해당 칸의 적이 결계에 주는 피해를 세기만큼 감소. 최솟값 0 |
| Dark / 암흑 | 해당 칸의 적이 결계에 주는 피해를 세기만큼 감소. 최솟값 0 |

필드별 세부 규칙이 기존 코드에 없어서 위 규칙을 기본 동작으로 정의했습니다. ROE 타일의 직접 데미지와 필드 세기는 별도 값입니다. 필드 설치에는 Damage 플래그가 필요하지 않으며, 적이 없는 칸이나 직접 공격으로 적이 죽은 칸에도 설치됩니다. 범위 밖·실제 타일이 없는 칸은 설치하지 않습니다.

클릭한 좌표와 회전된 ROE를 기준으로 설치하고, 이후 적이 들어오면 그 적에게 적용합니다. 칸당 필드는 하나이며 같은 칸에 다시 시전하면 종류·세기·남은 턴·시전자를 새 설정으로 교체합니다. 빈 칸도 지속 턴을 소모합니다. 바람으로 다른 필드에 들어간 적은 다음 적 턴부터 그 필드의 영향을 받습니다. 아군은 필드의 영향을 받지 않습니다.

여러 칸을 차지하는 몬스터는 모든 점유 칸의 필드를 검사합니다. 화염·전기는 닿은 몸 칸의 실드를 각각 제거하고, 실드가 없던 칸 중 가장 큰 값으로 본체에 종류별로 한 번 피해를 줍니다. 실드는 양수 피해 한 번을 전부 막으며 그 턴에 HP로 남은 피해가 넘어가지 않습니다. 같은 종류의 약한 필드도 해당 칸의 실드를 제거하고 지속 턴을 소모합니다. 서로 다른 피해 종류는 각각 적용하며, 처치 보상은 HP 피해를 낸 노출 칸의 필드 시전자에게 부여합니다.

화염·전기 피해를 현재 몸 칸에서 먼저 처리하고 바람 이동을 적용하므로, 이동 후 다른 몸 칸의 실드를 잘못 제거하지 않습니다. 얼음·바람·대지·암흑의 제어는 실드와 관계없이 적용합니다. 대지와 암흑의 피해 감소는 큰 값 하나를 사용하고, 바람도 가장 강한 값으로 한 번 밀칩니다.

필드 피해와 제어는 적의 결계 피해 계산보다 먼저 적용됩니다. 만료되는 마지막 턴에도 얼음/피해 감소가 적용됩니다. 필드 처치는 일반 사망 처리를 사용하며, 처치 수에 따른 이동력 패시브 보너스는 다음 아군 턴의 이동력 초기화 뒤 반영합니다. 웨이브 사이에는 남은 필드가 유지되고, 전투 종료·재진입·맵 전환 시 제거됩니다.

필드는 타일 색상과 커서 대상 정보의 종류·세기·남은 턴으로 표시합니다. 스킬/이동 미리보기를 취소하면 필드 색상을 복구합니다. 별도 Scene 오브젝트나 매니저 컴포넌트를 추가할 필요 없이 BattleManager가 런타임 상태를 관리합니다.

```bash
python Tools/PassiveTests/run_tests.py
```

실제 스킬 시전·턴 처리 소스를 Unity API double과 컴파일하여 빈 칸 설치, 회전/좌표 변환, 지속 피해/만료, 각 필드 규칙, 덮어쓰기, 하이라이트 복구, 처치 보너스, 맵 격리와 전투 정리를 검증합니다. Unity의 실제 렌더링·에셋 직렬화·Play Mode 검증은 별도로 필요합니다.
